คู่มือการใช้งานระบบเทรด BugTraderYai

ยินดีต้อนรับสู่ศูนย์ข้อมูลเชิงเทคนิค หน้าเอกสารนี้ถูกออกแบบมาเพื่อให้ข้อมูลที่เชื่อถือได้สำหรับการติดตั้งและบริหารจัดการความเสี่ยงด้วยระบบ EA

1. การติดตั้ง Expert Advisor (EA)

ทำตามขั้นตอนดังนี้เพื่อเริ่มต้นการทำงานของระบบ:

  • เปิดโปรแกรม MetaTrader 4 หรือ 5
  • ไปที่เมนู File > Open Data Folder
  • วางไฟล์ EA ในโฟลเดอร์ MQL/Experts

รูปที่ 1: การจัดการไฟล์ในระบบ MetaTrader

2. การตั้งค่าพารามิเตอร์ (Input Parameters)

การตั้งค่าเน้น Safety Mode เพื่อความยั่งยืนของพอร์ตการลงทุน

Parameter คำอธิบาย ค่าที่แนะนำ (Safety Mode)
Lot Size ขนาดของการส่งคำสั่งเทรด 0.01 ต่อทุน $1,000
Max Spread ค่า Spread สูงสุดที่ยอมรับได้ 20-30 points
ข้อควรระวัง: การลงทุนมีความเสี่ยง โปรดทดสอบระบบใน Demo Account ก่อนการใช้งานจริงทุกครั้ง
