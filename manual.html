SYSTEM MANUAL PROTOCOL

เอกสารฉบับนี้สรุปขั้นตอนทางเทคนิคสำหรับการติดตั้งและตั้งค่าระบบ Expert Advisor (EA) ภายใต้สภาพแวดล้อมที่เน้นความปลอดภัยสูงสุด (Safety-First Architecture)

1. การเตรียมความพร้อมของระบบ

ก่อนเริ่มการติดตั้ง โปรดตรวจสอบทรัพยากรของท่านดังนี้:

  • MT4/MT5 Terminal เวอร์ชันล่าสุด
  • VPS ที่มีความเสถียร (Latency < 50ms แนะนำ)
  • บัญชีเทรดที่มีเงินทุนสอดคล้องกับกลยุทธ์

2. ขั้นตอนการติดตั้ง (Installation)

การจัดการไฟล์ในระบบ MetaTrader ต้องทำอย่างระมัดระวังเพื่อให้ระบบทำงานได้สมบูรณ์:

  • ไปที่เมนู File > Open Data Folder ในโปรแกรมเทรด
  • เข้าไปที่โฟลเดอร์ MQL4/Experts หรือ MQL5/Experts
  • นำไฟล์ .ex4 หรือ .ex5 ที่ดาวน์โหลดมาวางในโฟลเดอร์นี้
รูปที่ 1: การเข้าถึงไดเรกทอรีระบบผ่าน Data Folder

3. การตั้งค่าพารามิเตอร์ (Safety Mode)

พารามิเตอร์เหล่านี้ถูกออกแบบมาเพื่อคุมความเสี่ยง ไม่ใช่เพื่อรีดกำไรสูงสุด:

Parameter Name Function Recommended Setting
Fixed Lot Size ขนาดสัญญาเริ่มต้น 0.01 ต่อ $1,000
Max Spread ค่าสเปรดสูงสุดที่ยอมให้เปิดออเดอร์ ไม่เกิน 25 points
Stop Loss (Pips) จุดตัดขาดทุนต่อไม้ ตามความเหมาะสมของกลยุทธ์
ATTENTION: ข้อมูลทางเทคนิคทั้งหมดเป็นเพียงแนวทางเบื้องต้น การใช้งานจริงต้องผ่านการทดสอบในสภาพแวดล้อมจำลอง (Demo) จนมั่นใจในตรรกะของระบบเท่านั้น
