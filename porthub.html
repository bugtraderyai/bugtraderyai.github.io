PHASE 1

สำหรับผู้ใช้งาน

เส้นทางของพาร์ทเนอร์ตั้งแต่สมัครสมาชิก จนข้อมูล MT4/MT5 ซิงก์ขึ้นแดชบอร์ดและเชื่อมต่อระบบแจ้งเตือน

01 สมัครสมาชิกและเข้าสู่ระบบ

การเข้าถึงแพลตฟอร์มอย่างเป็นระบบ ควรสมัครผ่าน Gateway Link ของทีมงาน เพื่อรับการเชื่อมต่อเข้ากับเครือข่ายอย่างสมบูรณ์

  1. คลิกที่ลิงก์เชื่อมต่อระบบ:
    ➜ เข้าสู่หน้าสมัครสมาชิก
  2. กรอกอีเมลและรหัสผ่าน หรือเลือก ดำเนินการต่อด้วย Google
  3. หากสมัครด้วยอีเมล ระบบจะส่งลิงก์ยืนยันไปที่ Inbox ให้ทำการกดยืนยันให้เรียบร้อย
  4. ระบบจะพาเข้า แดชบอร์ด พื้นฐาน (รองรับ 1 พอร์ตฟรี)
ข้อควรระวัง: รหัสแนะนำ (Affiliate Code) 95AD4C77E6 จะถูกฝังไว้ในลิงก์แล้ว ไม่สามารถใส่ย้อนหลังได้ กรุณาสมัครผ่านลิงก์ด้านบนเท่านั้น

02 แดชบอร์ดติดตามพอร์ต

ศูนย์บัญชาการข้อมูล (Command Center) รวมทุกบัญชีเทรดไว้ในหน้าเดียว โครงสร้างข้อมูลเรียงตาม พอร์ต → EA/ระบบเทรด → ออเดอร์

  • การ์ดสรุป KPI — ยอดเงิน, Equity, จำนวนออเดอร์ และกำไร/ขาดทุนลอยตัวแบบ Real-time (แพ็กเกจ Pro)
  • การจัดเรียง (Sorting) — วิเคราะห์ข้อมูลตามมูลค่าพอร์ต หรือกำไรลอยตัว
  • สวิตช์สาธารณะ — เปิดเพื่อส่งข้อมูลขึ้น Leaderboard (ต้องใช้ Pro)

03 เชื่อมพอร์ตด้วย PortHub Bridge EA

กลไกการส่งข้อมูลจาก Terminal สู่ Web Dashboard จำเป็นต้องรัน Bridge EA บนเครื่องหรือ VPS เดียวกันกับที่เปิด MT4/MT5 ไว้

  1. ไปที่ API Keys ตั้งชื่ออ้างอิงเครื่อง (เช่น VPS-Stealth-01) แล้วกด สร้าง API Key
  2. คัดลอก Token ที่ได้เก็บไว้
  3. ติดตั้งไฟล์ PortHub Bridge ลงในแฟ้ม Experts ของ MetaTrader
  4. ลาก EA ใส่กราฟเปล่า นำ Token ไปวางในช่อง InpApiKey
  5. เปิดปุ่ม AutoTrading / Algo Trading บนแถบเมนู (ต้องเป็นสีเขียว)
CHECKLIST: หากข้อมูลไม่ขึ้น ให้ตรวจสอบ 1. Algo Trading เปิดหรือไม่ 2. อนุญาต WebRequest ในออปชั่นของ MT4/MT5 หรือยัง 3. VPS มีสัญญาณอินเทอร์เน็ตปกติหรือไม่

04 ปฏิทินเทรด (Trading Calendar)

ระบบประมวลผล P&L รายวันจาก Closed Deals (รวม Swap และ Commission) สร้างสถิติอ้างอิงสำหรับการวิเคราะห์เชิงลึก

05 อันดับพอร์ต (Leaderboard)

ระบบจัดอันดับอิงตาม Performance จริง พอร์ตที่ถูกตั้งค่าเป็นสาธารณะ (ผ่านแพ็กเกจ Pro) จะได้รับลิงก์สำหรับแชร์ผลงานทางสถิติให้บุคคลภายนอกตรวจสอบได้โดยไม่ต้อง Login

06 การแจ้งเตือน (System Alerts & Push Notifications)

ตั้งค่า Protocol การเฝ้าระวังพอร์ต เมื่อตัวเลขถึงเกณฑ์ที่กำหนด ระบบจะยิงสัญญาณแจ้งเตือนเข้า Telegram หรือแจ้งเตือนแบบ Push บนมือถือทันที

  • Drawdown Alert — แจ้งเตือนเมื่อ DD พุ่งสูงกว่าค่า % ที่ตั้งไว้
  • Terminal Status — แจ้งเตือนทันทีเมื่อ VPS หลุด หรือ EA หยุดทำงานเกินเวลา
  • Daily Summary — บอทสรุปผลประกอบการเข้า Telegram ทุกวันตามเวลาที่ระบุ
TELEGRAM SETUP: ค้นหา @BotFather ใน Telegram → พิมพ์ /newbot → นำ Token ที่ได้มาใส่ในระบบ PortHub เพื่อเปิดใช้งานบอทส่วนตัว

07 แพ็กเกจ & Wallet

ขับเคลื่อนระบบผ่าน PortHub Wallet เติมเงินด้วย QR PromptPay (สแกนผ่านแอปธนาคารและแนบสลิปเพื่อตรวจอัตโนมัติ) เพื่อใช้อัปเกรดความเร็วในการดึงข้อมูลเป็นระดับ Real-time (แพ็กเกจ Pro)

08 แนะนำเพื่อน (Affiliate Program)

เมื่อคุณมีบัญชีแล้ว คุณสามารถใช้ระบบแนะนำเพื่อสร้างโครงสร้างเครือข่ายของตนเองได้

  • คัดลอกลิงก์ Affiliate ประจำตัวจากเมนู จัดการ → แนะนำ
  • รายได้จาก Affiliate แยกกระเป๋ากับ Wallet หลัก
  • สามารถสั่งถอนรายได้เข้าบัญชีธนาคาร (ผ่านการอนุมัติ) หรือโอนเข้า Wallet เพื่อใช้งานในระบบต่อได้ทันที
อย่าลืม: สำหรับการเริ่มต้นใช้งานของคุณเอง ให้สมัครผ่าน ลิงก์ระบบ (Ref: 95AD4C77E6) นี้เท่านั้น

09 ตั้งค่าบัญชี (Account Settings)

จัดการข้อมูลโปรไฟล์, ชื่อที่แสดงผล (Display Name), และความปลอดภัยของรหัสผ่าน รองรับการปรับเปลี่ยนภาษาของหน้าต่างการทำงาน

10 ติดตั้งแอปพลิเคชัน (PWA Installation)

PortHub ถูกออกแบบด้วยสถาปัตยกรรม PWA (Progressive Web App) สามารถติดตั้งลงบนหน้าจอโฮมของ Smartphone ได้โดยตรง

  • iOS (Safari): กดปุ่มแชร์ด้านล่าง → เลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen) (จำเป็นอย่างยิ่งเพื่อให้ Push Notification ทำงานได้)
  • Android (Chrome): กดเมนู 3 จุดมุมขวาบน → เลือก "ติดตั้งแอป" (Install App)
