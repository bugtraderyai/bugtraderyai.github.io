สำหรับผู้ใช้งาน

เส้นทางของลูกค้าตั้งแต่สมัครสมาชิก จนพอร์ต MT4/MT5 ขึ้นบนแดชบอร์ดและได้รับการแจ้งเตือนบนมือถือ

01 สมัครสมาชิกและเข้าสู่ระบบ

สมัครได้ทั้งด้วยอีเมล + รหัสผ่าน หรือเข้าด้วยบัญชี Google ถ้าสมัครด้วยอีเมล ระบบจะส่งลิงก์ยืนยันไปที่กล่องจดหมาย ต้องกดยืนยันก่อนจึงจะใช้งานแดชบอร์ดได้ครบ

  1. เปิด porthub.biz แล้วกด เริ่มต้นใช้งานฟรี ที่มุมขวาบน
  2. กรอกอีเมลและรหัสผ่าน หรือกด ดำเนินการต่อด้วย Google
  3. ถ้าสมัครด้วยอีเมล ให้เปิดเมลแล้วกดลิงก์ยืนยัน จากนั้นกลับมากด ฉันยืนยันแล้ว
  4. ระบบพาเข้า แดชบอร์ด โดยเริ่มที่แพ็กเกจ Free (1 พอร์ต)
มีรหัสแนะนำจากเพื่อน? ให้สมัครผ่านลิงก์แนะนำของเขาโดยตรง ระบบจะผูกรหัสให้อัตโนมัติ — ใส่ย้อนหลังไม่ได้

02 แดชบอร์ดติดตามพอร์ต

หน้าแรกหลังเข้าสู่ระบบ รวมทุกบัญชีที่เชื่อมต่อไว้ในหน้าเดียว โครงข้อมูลเป็นลำดับชั้น พอร์ต → EA / เทรดมือ → ออเดอร์ กดที่พอร์ตเพื่อกางกลุ่มเทรด และกดกลุ่มเพื่อดูออเดอร์ที่เปิดอยู่

  • การ์ดสรุปด้านบน — จำนวนพอร์ต, บัญชี, ออเดอร์, ยอดเงิน, Equity และกำไร/ขาดทุนลอยตัว (แปลงเป็น USD)
  • เรียงพอร์ตตาม — มูลค่าพอร์ต, ยอดเงิน, กำไรลอยตัว, จำนวนออเดอร์, สถานะออนไลน์, ชื่อ หรืออัปเดตล่าสุด
  • สาธารณะ / ส่วนตัว — สวิตช์ประจำพอร์ต เปิดเพื่อเผยแพร่ขึ้นอันดับพอร์ตและหน้าโปรไฟล์สาธารณะ
  • ความเร็วอัปเดต — Free/Standard อัปเดตทุก 1 ชั่วโมง ส่วน Pro เป็นเรียลไทม์ราว 5 วินาที

03 เชื่อมพอร์ตด้วย PortHub Bridge EA

พอร์ตจะขึ้นบนแดชบอร์ดได้ต้องมี EA ส่งข้อมูลเข้ามา ขั้นตอนคือ สร้าง API Key → ติดตั้ง Bridge บนเครื่อง/VPS ที่รัน MetaTrader → แนบ EA ใส่ Key → เปิด AutoTrading

  1. ไปที่ จัดการ → API Keys ใส่ชื่อเครื่อง (เช่น MT5-Gold-Rider-1) แล้วกด สร้าง API Key
  2. กด คัดลอก API Key เต็ม เก็บไว้ — ใช้กับเครื่องนั้นเครื่องเดียว
  3. ไปที่ ติดตั้ง EA ดาวน์โหลดตัวติดตั้ง แล้วรันบนเครื่อง/VPS ที่เปิด MetaTrader อยู่
  4. ใน MetaTrader เปิดกราฟใดก็ได้ แล้วลาก PortHub Bridge ลงบนกราฟ
  5. ในหน้าต่างตั้งค่า EA วาง Key ลงช่อง InpApiKey กด OK แล้วเปิดปุ่ม AutoTrading
  6. เปิด MetaTrader ทิ้งไว้ ราวหนึ่งนาทีพอร์ตจะโผล่บนแดชบอร์ดเอง จากนั้นตั้งชื่อพอร์ตได้ตามใจ
ถ้าพอร์ตไม่ขึ้น: 1. AutoTrading เปิดอยู่ไหม (ปุ่มสีเขียว) 2. มุมขวาบนของกราฟมีหน้ายิ้มไหม 3. เครื่อง/VPS ต่อเน็ตอยู่ไหม

04 ปฏิทินเทรด

สรุปกำไร/ขาดทุนรายวันจากออเดอร์ที่ปิดแล้ว รวมค่าคอมมิชชันและ swap พร้อมกราฟ equity สีเขียวคือวันที่กำไร สีแดงคือวันที่ขาดทุน (สีเข้มหมายถึงยอดเงินสูง)

ปฏิทินอ่านจาก closed deals ที่ EA ส่งเข้ามา วันที่ตัดรอบตามเวลาไทย (Asia/Bangkok) จึงอาจไม่ตรงกับเวลาเซิร์ฟเวอร์ของโบรกเกอร์

05 อันดับพอร์ต และโปรไฟล์สาธารณะ

เปิดสวิตช์ สาธารณะ ที่พอร์ตแล้วพอร์ตนั้นจะขึ้นกระดานอันดับ และได้ลิงก์โปรไฟล์สาธารณะไว้แชร์ให้คนอื่นดูผลงานโดยไม่ต้องเข้าสู่ระบบ

  • ต้องใช้แพ็กเกจ Pro จึงจะเผยแพร่ขึ้นกระดานอันดับได้
  • พอร์ต Demo เผยแพร่บนกระดานไม่ได้ — จัดอันดับแยกจากพอร์ต Real

06 ตั้งค่าการแจ้งเตือน

PortHub เฝ้าพอร์ตให้ตลอดเวลา เมื่อเข้าเงื่อนไขที่ตั้งไว้จะแจ้งเตือนเข้ากระดิ่งในเว็บ เข้า Telegram และเด้งบนมือถือได้ ปรับค่าแล้วระบบบันทึกให้ทันที

เงื่อนไขที่ตั้งได้

  • ความเสี่ยง / Drawdown — Drawdown สูง, ขาดทุนวันนี้, ขาดทุนลอยตัวรวม, Equity ร่วง
  • Margin — Margin Level ต่ำ, เสี่ยง Margin Call
  • สถานะ Terminal — ขาดการเชื่อมต่อโบรกเกอร์ AutoTrading ถูกปิด หรือซิงก์ล้มเหลว
  • การ์ดสรุปรายวัน — ส่งการ์ดรูปภาพเข้า Telegram วันละครั้งตามเวลาที่ตั้ง
TELEGRAM SETUP: ค้นหา @BotFather ใน Telegram → พิมพ์ /newbot → นำ Token มาใส่ในระบบ

08 แนะนำเพื่อน (Affiliate)

แชร์ลิงก์แนะนำของคุณ ใครสมัครผ่านลิงก์นี้จะถูกนับเป็นของคุณ เมื่อเขาจ่ายเงินคุณจะได้ส่วนแบ่งเข้ายอด Affiliate ซึ่งแยกจาก Wallet

  • โอนเข้า Wallet — เข้าทันที ไม่ต้องรอแอดมินตรวจสอบ ใช้จ่ายใน PortHub ได้เลย
  • ถอนเข้าบัญชีธนาคาร — กรอกข้อมูลแล้วส่งคำขอ รอแอดมินอนุมัติ มียอดขั้นต่ำ

09 ตั้งค่าบัญชี

แก้ชื่อที่แสดง รูปโปรไฟล์ ภาษา (ไทย / English) และเปลี่ยนรหัสผ่าน ถ้าเข้าสู่ระบบด้วย Google จะไม่มีช่องเปลี่ยนรหัสผ่าน เพราะรหัสผ่านอยู่ที่ Google

10 ติดตั้ง PortHub เป็นแอปบนมือถือ

PortHub เป็นเว็บแอป (PWA) ที่ติดตั้งลงหน้าโฮมได้ เปิดแล้วเต็มจอเหมือนแอปทั่วไป และจำเป็นสำหรับผู้ใช้ iPhone ที่ต้องการให้แจ้งเตือนเด้ง

  • iOS (Safari): กดปุ่มแชร์ด้านล่าง → เลือก "เพิ่มไปยังหน้าจอโฮม" (สำคัญเพื่อให้ Push Notification ทำงาน)
  • Android (Chrome): กดเมนู 3 จุดมุมขวาบน → เลือก "ติดตั้งแอป"
