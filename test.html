Phase 01

🛡️ 1. หลักการคิดและความปลอดภัยก่อนเริ่มใช้งาน (Philosophy & Risk Protocol)

ยินดีต้อนรับสู่ศูนย์ข้อมูลเชิงเทคนิคของ BugTraderYai หน้าเอกสารฉบับนี้คือ Protocol ในการบริหารจัดการความเสี่ยงเชิงระบบอย่างยั่งยืน เราทำหน้าที่เป็น “เกราะป้องกันทางความคิด” (Mental Safety Layer) เพื่อช่วยคัดกรองทัศนคติและสร้างความเข้าใจที่ถูกต้องให้แก่ผู้ใช้งานก่อนเข้าสู่ตลาดจริง

Interactive System Showcase

📝 Dashboard EA THAILAND : ภาพรวมหน้าต่างควบคุมและฟังก์ชันการทำงานทั้งหมด
📝 Overview : ส่วนนี้ทำหน้าที่แสดงผลและสรุปรวมยอดสถิติในบัญชีของคุณ
📝 Manual Trade : โหมดสั่งการด้วยตนเอง เหมาะสำหรับเทรดเดอร์ที่มอนิเตอร์หน้าจอ
📝 Start Lot : Lot เริ่มต้น | ใส่ระยะ TP/SL : ระยะนับเป็นจุด | Clear TP/SL : ลบล้างเส้นออก
📝 Close Controls : ปิดออเดอร์ All / Buy / Sell / บวกทั้งหมด / ติดลบทั้งหมด | Partial Close : หักปิดครึ่งเมื่อถึงเป้า
📝 Auto Trade : การตั้งค่าให้ระบบ EA เริ่มต้นออกออเดอร์และบริหารหน้าตักอัตโนมัติ
📝 Auto All : เปิดออเดอร์แรกทั้ง Buy และ Sell (หากใช้ Indicator ต้องรอสัญญาณยืนยัน)
📝 Auto Buy : เปิดเฉพาะออเดอร์ Buy ในไม้แรกตามเงื่อนไขทางสถิติ
📝 Auto Sell : เปิดเฉพาะออเดอร์ Sell ในไม้แรกตามเงื่อนไขทางสถิติ
📝 Pending Stop Out : เปิดคำสั่ง Pending ดักทั้ง Buy Stop และ Sell Stop
📝 Zone Recovery : วางโซนดักราคาแบบปิงปองบน-ล่างเพื่อบริหารการกลับตัว
📝 Anti-Martingale : เพิ่มขนาดไม้ตามเมื่อกราฟเคลื่อนที่ถูกทางตามแนวโน้ม
📝 Martingale : คำนวณแก้ไม้เมื่อกราฟเคลื่อนที่ผิดทางตามค่าสถิติที่กำหนด
📝 Grid Mode : สั่งเปิดไม้แก้ทันทีเมื่อราคาวิ่งถึงระยะทางที่ระบุ
📝 Timeframe Filter : ต้องรอการปิดแท่งเทียนใน Timeframe นั้นก่อน จึงจะทำการแก้ไม้
📝 Parameter Tuning : กำหนดระยะถัว (จุด), ตัวคูณ Multi Lot, และระยะ TP/SL อย่างแม่นยำ
📝 Trailing Stop : สร้างเส้น Stop Loss ล็อกหน้าทุนอัตโนมัติเมื่อราคาวิ่งถูกทางถึงระยะที่ตั้งไว้
📝 Target Profit Today : สั่งให้ระบบหยุดการเทรดทันทีเมื่อทำกำไรถึงเป้าประจำวัน ($ หรือ %)
📝 Hedging System : เปิดออเดอร์ฝั่งตรงข้ามเพื่อคานความเสี่ยงและรักษาสภาพคล่อง
📝 Hedging Manual : เลือกเปิดออเดอร์คานความเสี่ยง 10% - 100% ของ Lot รวมปัจจุบัน
📝 Hedging Auto Trade : ระบบจะออกไม้คานให้อัตโนมัติเมื่อค่า Drawdown (%) หรือจำนวนไม้ถึงเกณฑ์
📝 Hedging Technical : กลยุทธ์แก้ไม้ฝั่ง Hedging (Martingale / Anti-Martingale / แยก TP ฝั่งคาน)
📝 Profit Cancel Loss : ระบบจับคู่ปิดไม้กำไรตัดขาดทุนไม้ลบ (Last to First / Recover 1-1)
📝 Group Order Step : กำหนดระยะแก้ไม้แบบขั้นบันไดยืดหยุ่นตามพฤติกรรมราคา
📝 Rebalance : เมื่อกำไรรวมถึงเป้า ระบบจะเคลียร์ปิดออเดอร์ทุกคู่เงินทั้งหมดทันที
📝 Indicators : เลือกระบบสัญญาณทางเทคนิคเพื่อเป็นตัวกรองในการเปิดไม้แรก
📝 Functions : โมดูลเสริมความปลอดภัยและระบบช่วยควบคุมการทำงานรอบด้าน
📝 Mode Trade Now : สั่งเปิดออเดอร์ทันทีตามราคาตลาดแบบเรียลไทม์
📝 Mode Trade Pending : สั่งส่งเป็นคำสั่ง Pending Order ตามระดับราคาที่คำนวณ
📝 Mode Multi Lot : เลือกใช้สูตรตัวคูณขนาดไม้ตามตารางอัตราเร่ง
📝 Mode Plus Lot : เลือกใช้การเพิ่มขนาด Lot แบบคงที่ทีละสเต็ป
📝 TP Average : รวมจุดทำกำไรเป็นเส้นค่าเฉลี่ยเส้นเดียวทั้งพอร์ต
📝 TP Per Order : แยกเส้น Take Profit อิสระของแต่ละออเดอร์
📝 Fix Next Indicators : ต้องรอสัญญาณ Indicator เกิดขึ้นซ้ำอีกครั้งจึงจะออกไม้แก้
📝 Fix Next Candle : ต้องรอแท่งเทียนใหม่ตามเงื่อนไขยืนยันจึงจะออกไม้แก้
📝 Spread Filter : หากค่า Spread ตลาดสูงเกินเพดานที่กำหนด ระบบจะระงับการเปิดไม้แรก
📝 Day Time Filter : กำหนดตารางวันและช่วงเวลาอนุญาตให้ระบบทำงานอย่างเคร่งครัด
Phase 02

⚙️ 2. ขั้นตอนการติดตั้งและเตรียมความพร้อมของระบบ (System Implementation)

การเริ่มต้นใช้งานระบบภายใต้การดูแลของ BugTraderYai จะให้ความสำคัญกับการปรับจูนทัศนคติเรื่องความเสี่ยงเป็นลำดับแรก

💡 ข้อพึงระลึกเชิงระบบ: ระบบอัตโนมัติทุกประเภทล้วนมีข้อจำกัด หน้าที่สำคัญของนักลงทุนไม่ใช่การมองหากำไรสูงสุด แต่คือการทำความเข้าใจพารามิเตอร์และการจำกัดความเสียหายให้ถ่องแท้
⚠️ Safety Protocol

ข้อควรระวังเชิงระบบที่ต้องปฏิบัติตามอย่างเคร่งครัด

  • ทดสอบระบบในบัญชี Demo หรือ Forward Test ความเสี่ยงต่ำอย่างน้อย 2-4 สัปดาห์
  • ตรวจสอบการเชื่อมต่อ VPS (Virtual Private Server) ให้มีความเสถียรตลอด 24 ชั่วโมง
  • ห้ามแทรกแซงการทำงานด้วยการเทรดมือ (Manual Trade) ทับซ้อนในคู่เงินที่ระบบกำลังบริหาร
  • ระบบที่มีค่า Drawdown ในอดีตต่ำ ไม่ได้แปลว่าจะไม่มีความเสี่ยงในอนาคต จงบริหารเงินต้นอย่างระมัดระวังเสมอ
